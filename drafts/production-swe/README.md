# Production SWE

A practical guide to building and operating production-grade Python services.

## Chapters

| Chapter | Topic |
|---------|-------|
| [01 — Foundations](./01-foundations/README.md) | Code quality, typing, error handling, logging |
| [02 — Tooling and Environment](./02-tooling-and-environment/README.md) | Project layout, dependency management, linting, pre-commit, editor setup |
| [03 — Testing](./03-testing/README.md) | Testing philosophy, pytest, mocking, integration/async testing, coverage |
| [04 — API Design](./04-api-design/README.md) | REST principles, FastAPI, versioning, auth, pagination, idempotency |
| [06 — Architecture Patterns](./06-architecture-patterns/README.md) | Layered architecture, DI, repository pattern, event-driven design, microservices |
| [07 — CI/CD and Automation](./07-cicd-and-automation/README.md) | Git workflows, pre-commit, GitHub Actions, release strategies, secrets management |
| [09 — Deployment and Infrastructure](./09-deployment-and-infrastructure/README.md) | Docker, Kubernetes, infrastructure as code, service mesh, scaling |

Chapters 05 and 08 are reserved for future topics.

## Reading Order

Chapters are numbered in intended reading order, but each is written to stand on its own —
jump to whichever topic is relevant to the problem in front of you.
